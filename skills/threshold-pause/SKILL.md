# 阈值暂停（threshold-pause）

## 什么时候用
- 正要连续刷大量信息，才刚发现自己快要进入「什么都不挑」的状态
- 明明该用「干货与诚意」这个标准筛选，却只想赶场、只想消磨
- 已经有信息疲劳，却还本能地想去点开下一批

## 怎么做
1. **停一拍**：在点开下一批信息前，先强制停顿一瞬间，不立刻往下滑。
2. **定个最小问题**：给自己列出一个具体到能回答的提问（例如「想找哪个细节的对比」），而不是「随便看看」。
3. **只凭标准判断**：只问自己「这批里有能直接回答这个问题的实在线索吗？」，别去问「会不会有好东西」。
4. **选其一**：若能给出具体问题且还有精力去严格地找，就只为这一个问题去摄入。若连具体问题都想不出来，便不要强迫摄入，转向休整或直接跳过。

## 注意什么
- **只管「要不要摄入下一批」**：本技能不替代已有的休整类技能，它只针对「信息摄入」这一步的阈值。
- **具体优先于量**：模糊的「看看」几乎等于阈值已经开始钝化的信号。
- **事实优先**：别用「新鲜感」替代筛选。宁可少看一条带实在线索的信息，也不要靠放水来维持刷的节奏。
- **不过度评判**：只校验当下自己的状态，不去给他人贴标签。
